## ✨ Overview

**Web Games** is a collection of five standalone game projects, bringing classic puzzles and logic challenges together in one repository.

Each game has its own directory, making it easier to explore its implementation and work on it independently.

## 🚀 Quick Start

Clone the repository:

```bash
git clone https://github.com/ioarunkumar/web-games.git
cd web-games
```

Choose a game directory and follow its project-specific setup instructions.

## 📁 Project Structure

```text
web-games/
├── hangman/
├── knights-tour/
├── mastermind/
├── sliding-puzzle/
└── sudoku/
```

## ⚙️ How It Works

1. Choose a game.
2. Explore its source files.
3. Follow its setup instructions.
4. Play, experiment, or improve the implementation.
